# کتابخانه فارسی MD

یک برنامهٔ مدرن تحت وب و دسکتاپ برای مدیریت، جست‌وجو، مطالعه، ویرایش، گزارش‌گیری و ترجمهٔ کتاب‌های Markdown فارسی و عربی با رابط کاربری راست‌به‌چپ، پنل‌های شناور و موتورهای ترجمهٔ ماشینی و هوش مصنوعی.

---

## امکانات اصلی

- **کتابخوان و ویرایشگر Markdown**: مطالعهٔ صفحه‌به‌صفحه (جداشده با `---`)، پشتیبانی از پاورقی‌ها، جدول‌ها، بلوک‌های کد، نقل‌قول‌ها و ویرایش مستقیم متن و مشخصات (Front matter) کتاب‌ها با ذخیرهٔ اتمی.
- **پنل‌های شناور و قابل جابه‌جایی**:
  - **فیلتر و جست‌وجو**: فیلتر بر اساس بخش، پوشه، نویسنده، برچسب‌ها، برگزیده‌ها و وضعیت خوانده‌شده.
  - **جست‌وجوی تمام‌متن (Full-Text Search)**: جست‌وجوی زنده با استریم نتایج، پشتیبانی از حالت‌های همهٔ واژه‌ها، هر واژه، عبارت دقیق، Regex، جست‌وجوی فازی و شاخص‌گذاری پس‌زمینه.
  - **تنظیمات مطالعه و شخصی‌سازی**: تم‌های تاریک، روشن، سپیا و شیشه‌ای، انتخاب فونت (از جمله Vazirmatn)، اندازهٔ متن، گردی گوشهٔ پنل‌ها و مدیریت پوشهٔ داده‌ها.
  - **گزارش کتابخانه**: آمار کامل واژه‌ها، صفحه‌ها، حجم فایل‌ها، موارد تکراری و کتاب‌های دارای مشخصات ناقص همراه با خروجی `CSV` و `JSON`.
  - **ابزارهای گروهی (Batch)**: ویرایش گروهی فراداده (Front matter) و جست‌وجو و جایگزینی گروهی با پیش‌نمایش (Dry Run).
  - **نسخه‌های پشتیبان (Snapshots)**: تهیه و بازیابی نسخهٔ پشتیبان از کل کتابخانه یا پیش از ترجمهٔ هر کتاب.
- **خروجی گرفتن از کتاب‌ها**: دریافت فایل در قالب‌های `Markdown (.md)`، `HTML`، `Word (.docx)` و `PDF`.
- **سیستم ترجمهٔ هوشمند و بازبینی خودکار**:
  - حفظ کامل ساختار Markdown، پیوندها، جدول‌ها، کدها و پاورقی‌ها.
  - پشتیبانی از دو روند **صفحه‌به‌صفحه** و **ساختاری** (معلومات کتاب ← فهرست مطالب ← بدنه).
  - حافظهٔ ترجمه (`translation-memory.json`) و قابلیت بازبینی و ترمیم بخش‌های ترجمه‌نشده.
  - پشتیبانی از موتورهای:
    - **Google Gemini (رایگان)**: اتصال امن از سمت سرور با `@google/genai`، ارسال ترتیبی درخواست‌ها همراه با مکث خودکار بین ارسال‌ها و تلاش دوبارهٔ هوشمند برای جلوگیری از خطای محدودیت نرخ.
    - **گوگل ترنسلیت (رایگان)**
    - **LibreTranslate** (خودمیزبان / آفلاین)
    - **DeepL**
    - **سرویس‌های سازگار با OpenAI** (OpenAI، OpenRouter، Groq، DeepSeek، Ollama، LM Studio و…)
    - **Anthropic Claude**

## پیش‌نیازها

- **Node.js** نسخهٔ `20.19` یا بالاتر
- کلید `GEMINI_API_KEY` در متغیرهای محیطی سرور (برای استفاده از موتور رایگان جمنای)

---

## نصب و اجرا

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه (یکپارچه روی پورت 3000)
npm run dev
```

پس از اجرا، برنامه و API هر دو روی آدرس زیر در دسترس هستند:

```text
http://localhost:3000
```

---

## ساخت نسخهٔ نهایی و دسکتاپ

```bash
# بررسی تایپ‌ها (TypeScript)
npm run typecheck

# ساخت نسخهٔ تولید (سرور + کلاینت)
npm run build

# اجرای نسخهٔ تولید روی پورت 3000
npm start

# اجرای برنامهٔ دسکتاپ Electron
npm run electron

# ساخت نصاب ویندوز (NSIS)
npm run build:electron:win

# ساخت نسخهٔ قابل‌حمل (Portable)
npm run build:portable
```

## متغیرهای محیطی

نمونهٔ فایل تنظیمات در `.env.example` قرار دارد:

| متغیر | توضیح | مقدار پیش‌فرض |
| --- | --- | --- |
| `PORT` | پورت سرور برنامه و API | `3000` |
| `GEMINI_API_KEY` | کلید API جمنای در سمت سرور | — |
| `LIBRARY_DIR` | مسیر پوشهٔ کتاب‌های Markdown | `./data` |
| `APP_STORAGE_DIR` | مسیر ذخیرهٔ تنظیمات و حافظهٔ ترجمه | `./storage` |
| `APP_BACKUP_DIR` | مسیر ذخیرهٔ نسخه‌های پشتیبان | `./backups` |

## میان‌برهای صفحه‌کلید

| کلید | عملکرد |
| --- | --- |
| `/` | جست‌وجو در کتابخانه |
| `F` | باز/بسته‌کردن پنل فیلترها |
| `S` | باز/بسته‌کردن پنل تنظیمات |
| `G` | باز/بسته‌کردن گزارش کتابخانه |
| `T` | باز/بسته‌کردن ابزارهای گروهی |
| `R` | تازه‌سازی کتابخانه |
| `Esc` | بستن پنل‌ها و پنجره‌ها |

## ساختار پروژه

- `server.ts` و `server/` — سرور Node.js، اندپوینت‌های API، موتور جست‌وجو، گزارش‌گیری، پشتیبان‌گیری، خروجی و مترجم
- `src/` — رابط کاربری React + TypeScript + Vite
- `electron/main.cjs` — پوستهٔ دسکتاپ Electron
- `scripts/` — اسکریپت‌های توسعه و ساخت نسخهٔ قابل‌حمل
- `data/` — پوشهٔ کتاب‌های Markdown
